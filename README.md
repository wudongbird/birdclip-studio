# 落句排版室

SillyTavern 第三方前端扩展。用于把聊天片段制作成书摘图片。

当前版本：2.3.0。

模板采用 `birdclip-template` JSON 格式，可在编辑器内制作、保存、导出和分享；导入后会直接出现在模板库中。

## 安装

1. 在 GitHub 新建公开仓库，建议命名为 `birdclip-studio`。
2. 把本目录中的所有文件上传到仓库根目录。`manifest.json` 必须位于根目录，不能再套一层文件夹。
3. 打开 SillyTavern → 扩展 → 安装扩展。
4. 粘贴仓库地址，例如 `https://github.com/你的用户名/birdclip-studio`。
5. 选择 **Install just for me**，安装完成后刷新页面。

安装成功后，魔法棒菜单底部会出现“落句排版室”。

## 功能

- 3 个内置模板与可自定义尺寸的空白模板
- 切换模板只改变排版样式，保留当前摘录与已经编辑的文字
- 新增、选择并拖动文字层
- 在聊天正文中长按选择任意段落，点击选区旁的“书摘”直接进入排版
- 也可从最近聊天列表或剪贴板摘录
- 内置霞鹜文楷、思源宋体、朱雀仿宋，按当前文字从 ZeoSeven FontsAPI 分片加载
- 也可上传 TTF、OTF、WOFF、WOFF2 字体文件；上传字体可随 JSON 模板分享
- 调整字号、字距、行距、宽度、旋转、对齐、颜色、透明度、描边与阴影
- 12 种低饱和文字色、10 组书摘背景预设，以及自定义取色
- 自定义背景图、渐变颜色与角度、压暗和颗粒纹理
- 将当前排版保存到个人模板库
- 导出 `.birdclip.json` 模板包并分享给其他用户
- 导入模板包后直接出现在模板库中
- 导出 PNG，并支持手机长按保存
- 日常编辑界面精简，模板管理、聊天摘录和高级参数按需展开
- 手机端使用悬停实时预览，修改模板、字体与配色时无需反复回到顶部
- 打开系统文件选择器时保持编辑器与当前作品，不会因返回酒馆而关闭

## 模板工作流

1. 选择内置模板或新建空白模板。
2. 编辑作品文字，拖动文字层并调整样式。
3. 点击“保存到模板库”，供自己重复使用。
4. 点击“导出分享模板”，生成 `.birdclip.json` 文件。
5. 其他用户点击“导入模板”，即可使用同一套排版。

模板包可包含背景图；模板库保存在浏览器的 IndexedDB 中，不会上传到服务器。

## 隐私

扩展不会上传聊天内容、图片、角色卡或 API Key。仅在使用三款在线内置字体时，请求 ZeoSeven FontsAPI 提供相应字形；使用系统字体或自行上传的字体时不需要该请求。

三款在线内置字体均采用 SIL Open Font License 1.1，来源和许可说明见 `THIRD_PARTY_FONTS.md`。

## 兼容性

- SillyTavern 1.14.0 及以上
- Android Chromium / Chrome 与桌面 Chromium 浏览器

## 更新

修改文件后同步到同一 GitHub 仓库，并更新 `manifest.json` 的版本号。随后在 SillyTavern 的“管理扩展”中执行更新。
